## Open from the FlyReq Dashboard

Users can jump directly from the FlyReq dashboard to the image generation page.

![推荐](/assets/flyreq_image/flyreq-image.png)


## Before You Start

Before using image generation, make sure:

1. You have a valid FlyReq account
2. Your account has available quota
3. You can access the image generation page

## Basic Workflow

1. Open [https://image.flyreq.com/](https://image.flyreq.com/)
2. Sign in or confirm the current account status
3. Enter an image generation prompt
4. Select the model, size, quantity, and other parameters
5. Start generation and wait for the result
![推荐](/assets/flyreq_image/p1.png)
6. Download or save the generated image

## Prompt Template

You can start with this structure:

```text
Subject: a futuristic mechanical cat
Scene: a blue neon city street
Style: cyberpunk, cinematic, highly detailed
Composition: full-body composition, high quality, sharp and clear
Negative: no text, no watermark, no malformed hands
```

## Notes

### Image Generation Failed

Check your account quota, prompt content, model availability, and network connection.

### The Result Does Not Match Expectations

Try adding more details about style, composition, lighting, colors, and camera language. Also clearly describe what should not appear.

### Cannot Find the Dashboard Shortcut

Confirm that image generation is enabled for your account, or contact FlyReq support to check permissions.
